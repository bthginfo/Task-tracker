# Fokus visual system
User direction: modern Apple-like SaaS interface, dark default, switchable light mode.
Operate mode: work clarity and comfortable daily use lead every decision.
Charcoal surfaces with restrained sage accent, locally hosted Inter, thin Lucide icons, precise separators, generous page gutters and compact task rows. A persistent sidebar anchors navigation; tasks open in an editing drawer. The task content is the main surface. Mobile uses a collapsible navigation and full-width editing panel.
Sage remains the default accent. Settings offers six coordinated accent palettes (sage, blue, violet, rose, apricot, teal), each with explicit light/dark tokens and accessible foregrounds. Accent preferences stay on the current device, matching theme preferences; semantic warning/error colors remain stable.
